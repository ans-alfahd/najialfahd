## جدول الحصص الأسبوعي

يتضمن المشروع صفحة تفاعلية لتنظيم جدول الحصص الأسبوعي لجميع صفوف المرحلة
الابتدائية (من الأول إلى السادس) مع شعبتي (أ) و(ب) لكل صف. يعرض الجدول الأيام
من السبت إلى الخميس وست حصص يوميًا، ويمكن تخصيص كل خانة بمادة ومعلم وملاحظات
اختيارية.

### كيفية الاستخدام

1. افتح الملف `index.html` في المتصفح.
2. أضف المواد والمعلمين من خلال لوحات الإدارة أعلى الصفحة.
3. اضغط على زر **إضافة حصة** في أي خانة لاختيار المادة والمعلم المناسبين وإضافة
   ملاحظات عند الحاجة.
4. استخدم أزرار **تعديل** و**حذف** داخل كل خانة لتعديل توزيع الحصص أو إفراغها.
